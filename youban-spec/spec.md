# 游伴 Youban — Splash Screen 加载动画需求规格说明书

版本：v1.0 · 2026-08-01

## 1. 背景与目标

### 1.1 产品背景

游伴（Youban）是一位陪伴用户探索世界的高端 AI 旅行助手。当前用户打开页面看到的是常规加载等待，缺乏品牌感知与情绪价值。

### 1.2 目标

将「等待加载」转化为「开启一次旅程」：

> 用户打开页面时，看到一束温暖晨光照亮地图，旅行路线逐渐展开，一个智能旅伴正在准备陪他出发。

### 1.3 成功指标

| 指标 | 目标 |
|---|---|
| 首屏动画可感知延迟 | ≤ 500ms（动画先行，不阻塞应用初始化） |
| 帧率 | 桌面 60 FPS / 移动端 ≥ 30 FPS（降级档位） |
| 完整动画时长 | 3–5s，可随实际加载完成时间自适应收尾 |
| 跳过能力 | 点击 / 加载完成即跳过，不强制看完 |
| 兼容性 | 主流桌面与移动端浏览器（WebGL2 不可用时优雅降级） |

## 2. 设计基调

### 2.1 视觉风格（必须）

- Anthropic Claude 暖色美学：暖米色、奶油白、浅沙色、柔和金色
- 温暖、自然、智能、优雅；极简但有情绪
- 未来感与旅行感结合，高级 AI 产品体验

### 2.2 反模式（禁止）

- ❌ 黑色背景、暗色系主导
- ❌ 赛博朋克、霓虹、HUD 元素
- ❌ 冰冷蓝色科技风
- ❌ 游戏式 Loading 条 / 转圈 spinner 作为主视觉
- ❌ 复杂 UI、文字堆叠
- ❌ 真实地图图片 / 贴图素材（必须 Shader 程序化生成）
- ❌ 高速科幻 Warp 转场

## 3. 用户体验流程

### 3.1 阶段一：旅程开启（0–40%）

**画面**：全屏暖米色 / 奶油白 / 浅沙色渐变背景，质感类似清晨天空或旅行笔记纸张。中央出现柔和金色光源。

**光源行为**：
- 像太阳从地平线升起，光芒缓慢扩散
- 柔和 Bloom 泛光
- 轻微体积光（光穿过空气的感觉）

**粒子环境**：
- 大量细小漂浮粒子，像阳光中的尘埃
- 部分粒子带金色暖调
- 缓慢旋转、流动、聚合

### 3.2 阶段二：旅行世界形成（40–80%）

- 光粒子获得方向性运动，聚集形成地球轮廓
- 轻微发光的经纬线浮现
- 城市节点逐渐亮起（金色光点）
- 抽象地图纹理从光中浮现（程序化生成，非真实地图）

**感受**：一个微缩世界正在苏醒。

### 3.3 阶段三：进入游伴世界（80–100%）

- 地球光球逐渐扩大，摄像机缓慢向前推进
- 用户像穿越一道温暖的旅行之门，光线包裹整个屏幕
- 温暖光芒 → 穿越世界 → 光线消散
- 过渡到游伴主界面（行程脉络 / 景点地图 / 每日计划 / 预算规划 / AI 旅行助手）

### 3.4 中断与降级

- 应用数据提前加载完成：动画平滑加速进入阶段三收尾，不生硬截断
- 用户点击屏幕：立即触发收尾转场
- WebGL2 不可用 / 低性能模式：降级为 2D Canvas 或 CSS 暖光渐变 + 品牌 Logo 淡入
- 重复访问（可选）：`sessionStorage` 标记，二次进入缩短为精简版（≤1.5s）

## 4. 功能需求

| ID | 需求 | 优先级 |
|---|---|---|
| FR-1 | 全屏 Splash 覆盖层，挂载于应用入口，加载完成后移除 | P0 |
| FR-2 | 三阶段连续动画：晨光 → 地球形成 → 穿越转场 | P0 |
| FR-3 | 阶段进度与实际加载进度可绑定（也支持纯时间驱动兜底） | P0 |
| FR-4 | 点击跳过，平滑收尾 | P0 |
| FR-5 | 设备性能检测与自动降级（粒子数 / Shader / Bloom） | P0 |
| FR-6 | WebGL2 不可用的静态降级方案 | P0 |
| FR-7 | 转场结束与主界面无缝衔接（白场过渡，无闪黑） | P0 |
| FR-8 | 重复访问精简版 | P2 |

## 5. 非功能需求

### 5.1 性能

- 桌面 60 FPS，移动端低档 ≥ 30 FPS
- 粒子系统全部 GPU 计算，无逐粒子 JS 更新
- 根据 `devicePixelRatio`、GPU 能力、设备类型分三档：
  | 档位 | 粒子数 | Bloom | Shader |
  |---|---|---|---|
  | High（桌面） | ~15,000 | 全质量 | 完整噪声 |
  | Medium | ~8,000 | 半分辨率 | 简化噪声 |
  | Low（移动低端） | ~3,000 | 关闭 | 基础渐变 |
- 总资源增量 ≤ 200KB（gzip，Three.js 按需引入 + 懒加载 chunk）

### 5.2 可访问性

- `prefers-reduced-motion: reduce` 时直接展示静态暖色品牌画面并尽快进入主界面
- Splash 层 `aria-hidden`，不干扰屏幕阅读器
- 无高频闪烁（闪烁频率 < 3Hz）

### 5.3 兼容

- Chrome / Safari / Edge / Firefox 最近两个大版本
- iOS Safari、Android Chrome 移动端

## 6. 验收标准

1. 打开页面 500ms 内出现暖色渐变背景与金色光源
2. 三个阶段视觉连贯，无跳帧感、无黑场、无冷色元素
3. 地球轮廓、经纬线、城市光点全部由 Shader 程序化生成（代码中无地图图片资源）
4. 转场结束直接进入主界面，背景色无缝衔接
5. 低端移动设备上帧率稳定，不出现明显掉帧或发热卡顿
6. 点击任意处可跳过
7. `prefers-reduced-motion` 用户看到静态版本

## 7. 范围外（Out of Scope）

- 音效 / 配乐（后续迭代考虑）
- 个性化（根据用户目的地定制地球节点）
- WebGPU 路径
