# 游伴(youban)App 图标重设计 · Design Spec

## 产品是什么
「游伴」是一款 AI 旅行规划产品:用户和 AI 聊着天,行程就定好了。核心人格是**旅途中的伙伴**,不是冷冰冰的规划工具。产品 UI 已全面采用暖色大地色系(Anthropic 式的温暖手工感),前身名为 "TripStar"。

## 为什么重做图标
现有图标(蓝圆底 + 白色 S 形航迹 + 飞机 + 星星)完全服务于旧名 TripStar:S = TripStar 首字母,星 = Star,冷蓝 = 旧调性。改名「游伴」后名不符实,且冷蓝与产品现在的暖色品牌冲突。

## 核心意象(用户已选定,不可偏离)
**「结伴同行」= 两个旅伴 + 一条路径。**
关键词:并肩、依偎、同路、温度。要传达的是**两个个体之间的关系**,不是效率感/导航感/机票酒店感。
视觉母题(本设计独有的最小证据):**两个形彼此靠近,共走一条路。**"二"是必须的——一个形不叫伴。

## 目标受众与使用场景
- 中文用户,休闲旅行者,期待有温度的 AI 助手
- 图标出现在:浏览器标签页 favicon(16px)、手机桌面 App 图标、产品内 logo 位

## 品牌色板(从产品 CSS 实测提取,只用这些色,禁止发明新色)
- 珊瑚红 `#D4625E`(主色,用量最大)
- 焦糖棕 `#C17F59`
- 桃橙 `#E8A87C`
- 琥珀金 `#E8B059`
- 鼠尾草绿 `#8FB996`(点缀,慎用)
- 奶油底 `#FAF7F2` / 米白 `#fffcf5`
- 深棕(文字/描边)`#3D3229` / `#5C4B3E`
**禁止冷蓝。禁止紫渐变。**

## 硬性技术约束
1. 图标本体 = inline SVG,`viewBox="0 0 512 512"`,矢量、可无损缩放
2. **16px 底线**:缩到 16×16 的 favicon 必须仍可辨识出"两个形 + 关系感"——细节超过 3 个层级就会糊,构成必须极简
3. 在**白色**和**奶油色 #FAF7F2** 两种背景上都成立(浏览器标签页两种主题)
4. 图形本身独立成立,不依赖文字;可另配"游伴"字标但不是主体
5. 三版的**图形构成结构必须互异**(不许三版都是"圆底 + 两个人形"换配色——构成逻辑本身要不同)

## 反 slop 红线
- 禁 SVG 画写实人物(五官/手脚细节)——用抽象几何表达"人/伴"
- 禁陈词滥调:定位 pin、指南针、飞机、地球仪(除非有真正的新解法融合进"伴"的意象)
- 禁 emoji、禁通用渐变球
- 珊瑚红是品牌签名,方案里应让它担纲

## 输出格式(三个方向统一,便于横向对比)
每方向一个**单文件 HTML**(纯 HTML/CSS/inline SVG,无外部依赖,双击即开),页面 1440×900 深浅适中的展示墙,含:
1. 512px 主图标大图(透明/奶油底)
2. iOS 风格圆角矩形 App 图标形态(图标 + 底色的组合)
3. 缩放测试行:64px / 32px / 16px 三档并排
4. 浏览器标签页模拟两枚:白底 tab + 奶油底 tab,标签文字「游伴」
5. 底部一行设计说明:构成逻辑一句话 + "form 来自内容的哪里"一句话
文件命名:`direction-a.html` / `direction-b.html` / `direction-c.html`
